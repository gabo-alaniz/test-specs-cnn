# Historia del template

Este índice resume las mejoras que dieron origen al template. Los artefactos internos y los enlaces al
repositorio de desarrollo no forman parte de la distribución.

## 001-sdd-integrity-hardening

Endureció gates, hashes de aprobación, transiciones y evidencia ligada al contenido probado.

## 002-agent-security-hardening

Corrigió escapes de rutas, comandos envueltos y contratos de permisos entre herramientas.

## 003-ci-template-lifecycle

Incorporó IDs serializados, CI reproducible, versiones y actualizaciones recuperables.

## 004-single-tool-ci

Hizo que los fixtures fueran independientes de las configuraciones de agentes presentes en el checkout.

## 005-root-consolidation

Redujo la raíz y documentó la inicialización del template sin perder capacidades.

## 006-ci-compatibility

Restauró compatibilidad Python 3.9 y permisos de lectura para la verificación de secretos.

## 007-sdd-governance-hardening

Vinculó rama, diff, spec y evidencia; agregó parsers estrictos, transacciones y métricas históricas.

## 008-size-s-lifecycle-fixes

Corrigió el ciclo size S, revisiones de diseño y fingerprints reproducibles de distribución.
